The three rules to remember

CURRENT IMPLEMENTATION
01
One open HTTP response, many SSE events.

The Worker returns a readable stream with HTTP 200 and text/event-stream. Gruuvii’s SDK parses each event; your app appends delta.content to its UI.

02
The coordinator chooses; the Worker carries the bytes.

The Durable Object receives routing metadata. Prompts and response bytes travel between the Worker and the selected provider. Provider credentials stay inside the router.

03
Fail over before streaming, never halfway through an answer.

A rejected upstream attempt can move to another provider. Once a successful streaming response is accepted, the router closes its failover window. A later failure ends that stream.
